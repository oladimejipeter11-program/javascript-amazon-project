# Amazon Project - JavaScript

An Amazon clone built with HTML, CSS, and JavaScript.

I built this project to learn how real e-commerce websites work.

## What I Learned
- HTML for page structure
- CSS for design and layout
- JavaScript for cart, products, and interactivity

## Features
- Product listing
- Add to Cart
- Cart quantity update

## How To Run It
1. Download or clone this repo
2. Open `amazon.html` in your browser
3. Start shopping
